# TiviPB26-ohjelmointi-(Bohdan Oksantiuk)
Palautetut tehtävät

Suoritin kaikki tehtävät itsenäisesti ja opin niiden aikana paljon uutta. Tekoälystä oli välillä apua tehtävien tekemisessä. Oli erittäin mielenkiintoista oppia uusia asioita, ja uskon, että pystyn hyödyntämään oppimaani myös tulevaisuudessa.
